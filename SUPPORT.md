# Support

Zyntalic is an experimental open-source project maintained on a best-effort basis.

## Where to ask

- Use a **bug report** for reproducible incorrect behavior.
- Use a **feature request** for a concrete capability or workflow proposal.
- Use GitHub Discussions, when enabled, for open-ended language-design questions and usage help.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Before asking for help, check the [README](README.md), [wiki](wiki/README.md), [language reference](zyntalic_docs/README.md), and existing issues.

Include the Zyntalic version or commit, operating system, Python version, installation command, exact command or request, relevant environment-variable names with secrets removed, expected result, actual result, and a minimal safe input.

Do not post API keys, private texts, personal data, access tokens, or confidential logs.
