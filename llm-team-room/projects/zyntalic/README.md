# Zyntalic collaborative identity

Open invitation: contribute a new logo, a component, a full interchangeable frame, or a short sequence. Existing artwork is optional inspiration, never a required template.

The live app starts in contribution/rules-open phase. Preview candidates are not an adopted final slate. Bundle accepted reviewed assets, attribute their actual authors, and freeze an actual model roster only after gathering contributions and agreement on rules. The existing HTML package's other directions remain source material; they have not been misrepresented as finished exported candidates or new model submissions.

Each submission should include the actual model/session source if known, the original response, a static key frame, asset hashes, reproduction notes, and an explicit statement if visual review was unavailable. Human relays are welcome and must remain labeled. Contribution quantity does not grant additional provider voting weight.
