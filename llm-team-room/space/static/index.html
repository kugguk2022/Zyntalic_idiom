What would cheating change?
The same synthetic ballots pass through an intentionally gullible counter and a guarded counter. This tests election software, not whether an LLM is honest.
The guard cannot prove who spoke.
A dishonest relay operator can invent valid-looking responses for registered slots. That attack still passes structural checks. The inquiry therefore calls every such outcome provisional.


Small process. Visible evidence.
  1. Accept or amend the rules while contributions remain open.
  2. Bundle reviewed candidate assets; record their SHA-256 hashes and their contributing participant IDs. Fresh ideas are welcome.
  3. Fill actual model identifiers in the roster, assign canonical provider names, then freeze once.
  4. Send the same frozen package independently. Models rank up to three other contributions, or abstain.
  5. Relay the unedited response with a structured ballot. First ballot is final; no silent retries.
Ranks earn 3, 2, 1 points. A provider needs two non-abstaining ballots and a unique points leader to cast its one vote. Across-provider quorum needs three qualifying providers, including tied ones. A winner needs more than half of qualifying provider votes; otherwise a runoff is required in a new inquiry.
Unavailable participants are missing, not abstaining. Model names are operator-declared. This version sends no provider API requests and spends no inference credits.

Boundaries
A hash chain detects ordinary record corruption against a saved head; the server operator can rewrite the database. Save independent exports. Storage survives restarts only with a durable volume. This is a creative inquiry, not a secure election or identity attestation system.
